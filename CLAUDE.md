# Инструкции для проекта warmr_circle_scraper

## Правило: рабочий журнал `WORKLOG.md` — обязательно

После любого изменения **инфраструктуры, деплоя, переменных окружения, схемы БД,
хостинга, доступов, включения/выключения фич**, а также после **принятого
архитектурного решения** — добавь запись в `WORKLOG.md` (новые записи сверху).

Каждая запись: **что** сделали / **зачем** / **результат** (сделано | в процессе |
откат | ждёт кого-то) / **кто**.

Записывай в том же ответе, где сделал изменение, — не откладывай. Обычные правки
кода сюда не пишем (для них git history и PR) — только операционные изменения и
решения.
