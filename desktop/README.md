# Warmr Circle — десктоп-приложение

Одно приложение делает всю воронку само: находит сообщества Circle, проверяет,
что они существуют, оценивает через LLM, подходят ли они нам, вступает в
подходящие через ваш браузер ego lite и читает все посты и комментарии. Данные
лежат в той же базе Supabase, что у старого дашборда.

## Почему десктоп, а не веб

- Вступать можно только из вашего настоящего браузера. Серверный браузер
  Circle закрывает проверкой Cloudflare и Turnstile. ego lite существует
  только для macOS.
- Чтение по кукам с сервера Railway с 16.09 ловит проверку Cloudflare. С
  домашнего IP те же куки работают (замер 18.09).
- HTML-страницы Circle закрыты проверкой даже с домашнего IP. Поэтому всё
  читается через JSON API Circle, а каталог discover.circle.so открывается во
  встроенном браузере приложения.

Итог: Mac — основная платформа. На Windows работает всё, кроме автоджойна.
Там в карточке сообщества есть «Вступить вручную»: вы вступаете сами в окне
приложения, а куки оно забирает автоматически.

## Установка

- **Mac:** `dist/Warmr Circle-0.1.0-mac-arm64.dmg`. Сборка без подписи Apple:
  при первом запуске откройте через правый клик → «Открыть».
- **Windows:** `dist/Warmr Circle-0.1.0-win-x64.exe`. Без подписи: SmartScreen
  попросит подтвердить «Подробнее → Выполнить в любом случае». На Windows
  сборка не проверялась.

## Первый запуск

1. **Настройки → Импорт из .env.** Выберите `.env` проекта: подтянутся строка
   базы (`CIRCLE_LEADS_DB`), логин и пароль Circle, ключи LLM, если есть.
   Секреты хранятся только на этом компьютере и шифруются системной связкой
   ключей (Keychain на Mac, DPAPI на Windows).
2. При первом подключении приложение создаёт в базе схему `warmr_app` со
   своими таблицами. Колонки в `public` не меняются.
3. **Ключ LLM** (OpenAI или Anthropic) — там же, в Настройках. Без ключа
   сообщества оцениваются только по правилам (ключевым словам).
4. **Старый воркер на Railway.** Пока он включён, он параллельно читает
   сообщества и переоценивает ICP. В Настройках есть кнопка выключить его
   расписание.
5. **ego lite** (для автоджойна): установите с lite.ego.app, войдите в Circle
   в его браузере, нажмите «Проверить ego lite».
6. Включите **Автопилот** слева внизу. Автоджойн включается отдельно в
   Настройках, потому что работает с вашим настоящим аккаунтом.

## Этапы

| Этап | Что делает | Когда |
|---|---|---|
| Поиск | Обходит каталог discover.circle.so, добавляет ваши списки, для подходящих карточек ищет настоящий адрес | раз в сутки |
| Проверка и ICP | `GET /internal_api/communities/current`: только JSON 200 доказывает, что сообщество существует. Затем названия публичных разделов и оценка LLM | каждые 20 минут, пока есть очередь |
| Вступление | ego lite, не больше 25 визитов в день, пауза 30–90 секунд. Вход, 2FA, анкеты и проверки становятся задачами для вас | раз в 4 часа, выключено по умолчанию |
| Чтение постов | Все разделы, все страницы, комментарии и ответы. Первый проход — вся история, дальше только новое | раз в 6 часов |

## Ограничения Circle, которые учтены

- **Лимит запросов общий на IP и на все сообщества.** 18.09 около 100
  запросов в минуту с одного Mac привели к 429 на все хосты Circle примерно
  на 15 минут. Регулятор приложения: 20 запросов в минуту, 600 в час, после
  первого 429 — пауза 60 минут. Не запускайте одновременно Python-скрипты
  обогащения или воркер на том же компьютере.
- **Около 94 визитов браузера в день** с одного аккаунта уже вызывали 2FA,
  поэтому лимит — 25 визитов в день. Он хранится в базе и общий для всех
  компьютеров.
- **Любой `*.circle.so` отвечает 401, даже выдуманный.** 401 не доказывает,
  что сообщество существует. Такие строки помечаются «закрыто или нет».

## Для разработки

```bash
cd desktop
npm install
npm run dev          # приложение с горячей перезагрузкой
npm test             # модульные тесты движка
npm run typecheck
npm run dist:mac     # установщик для Mac
npm run dist:win     # установщик для Windows (собирается и на Mac)
```

Если терминал запущен из VS Code, в окружении может стоять
`ELECTRON_RUN_AS_NODE=1`, и Electron тогда запустится как обычный Node.
Запускайте через `env -u ELECTRON_RUN_AS_NODE npm run dev`.

Интеграционные тесты ходят в настоящий Circle и пишут в базу, поэтому
запускаются только на одноразовой локальной базе, никогда на Supabase:

```bash
# Postgres на 127.0.0.1:55432 с базой warmr_test, заполненной
# scripts/seed_test_db.py (схема из моделей Python + выборка строк)
WARMR_TEST_DB=postgresql://postgres@127.0.0.1:55432/warmr_test npx vitest run tests/integration.test.ts
```

Устройство кода:

- `src/engine/` — вся логика воронки, без Electron: `circle/` (HTTP, регулятор,
  проверка, чтение), `stages/` (четыре этапа), `db/` (SQL и миграции), `icp/`,
  `llm/`, `join/` (мост к ego lite и проверенный сценарий вступления).
- `src/main/` — оболочка Electron: окно, трей, секреты, встроенный браузер,
  ручное вступление, IPC.
- `src/renderer/` — интерфейс на React.
- Точки совместимости с Python-приложением: `contentHash`/`simhash`, слаги и
  классификация `communities/current` совпадают побитово
  (`tests/parity.test.ts`, эталоны из самого Python-кода).
